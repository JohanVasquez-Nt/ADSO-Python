# Ejercicio 31. Mayor y menor elemento de una lista

## Enunciado

Desarrolle un programa que solicite la cantidad de números que se almacenarán en una lista. Luego, ingrese cada número y determine cuál es el mayor y cuál es el menor.

### Ejemplo de entrada

```text
Cantidad de números: 6

Números:
15
28
9
34
17
12
```

### Salida esperada

```text
Mayor: 34
Menor: 9
```

# Ejercicio 40. Gestión de una lista de compras

## Enunciado

Desarrolle un programa que permita registrar productos en una lista de compras. Solicite la cantidad de productos, almacénelos en una lista y muestre el listado completo al finalizar.

### Ejemplo de entrada

```text
Cantidad de productos: 5

Productos:
Arroz
Leche
Huevos
Pan
Café
```

### Salida esperada

```text
Lista de compras:

1. Arroz
2. Leche
3. Huevos
4. Pan
5. Café
```
