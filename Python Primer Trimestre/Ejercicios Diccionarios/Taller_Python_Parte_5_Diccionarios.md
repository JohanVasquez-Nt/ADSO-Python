# Ejercicio 41. Registro de estudiantes

## Enunciado

Desarrolle un programa que permita registrar la información de varios estudiantes utilizando un diccionario. Cada estudiante deberá almacenarse con su código como clave y su nombre como valor. Al finalizar, muestre el listado completo de estudiantes registrados.

### Ejemplo de entrada

```text
Cantidad de estudiantes: 3

Código: 101
Nombre: Laura

Código: 102
Nombre: Juan

Código: 103
Nombre: Camila
```

### Salida esperada

```text
Listado de estudiantes

101 -> Laura
102 -> Juan
103 -> Camila
```

## Enunciado

Desarrolle un programa que permita crear una agenda telefónica utilizando un diccionario, donde la clave será el nombre del contacto y el valor será su número telefónico. Al finalizar, solicite el nombre de un contacto y muestre su número.

Teléfono: 3155555555

Buscar contacto: Ana

```text
Teléfono de Ana: 3209876543
```

# Ejercicio 46. Sistema de notas

## Enunciado

Desarrolle un programa que permita registrar varios estudiantes con sus respectivas notas. Utilice un diccionario donde la clave sea el nombre del estudiante y el valor su nota final. Al finalizar, muestre el estudiante con la nota más alta.

### Ejemplo de entrada

```text
Cantidad de estudiantes: 4

Laura 4.5
Juan 3.8
Camila 4.9
Pedro 4.1
```

### Salida esperada

```text
El estudiante con la mejor nota es:

Camila -> 4.9
```

# Ejercicio 50. Sistema de gestión de estudiantes

## Enunciado

Desarrolle un programa que permita registrar varios estudiantes. Para cada estudiante almacene:

- Código
- Nombre
- Edad
- Carrera
- Promedio

Utilice un diccionario donde el código sea la clave y la información del estudiante sea el valor. Al finalizar, muestre la información del estudiante con el promedio más alto.

### Ejemplo de entrada

```text
Cantidad de estudiantes: 3

Código: 101
Nombre: Laura
Edad: 20
Carrera: Ingeniería
Promedio: 4.6

Código: 102
Nombre: Juan
Edad: 22
Carrera: Sistemas
Promedio: 3.9

Código: 103
Nombre: Camila
Edad: 21
Carrera: Electrónica
Promedio: 4.9
```

### Salida esperada

```text
Mejor estudiante

Código: 103
Nombre: Camila
Edad: 21
Carrera: Electrónica
Promedio: 4.9
```
