# Taller de Python

## Parte 1 -- Variables y Operaciones Básicas

## Ejercicio 1. Cálculo del salario de un empleado

### Enunciado

Desarrolle un programa que solicite el nombre de un empleado, la
cantidad de horas trabajadas y el valor de la hora. El programa debe
calcular el salario total e imprimir toda la información.

**Ejemplo de entrada**

``` text
Nombre: Juan Pérez
Horas trabajadas: 48
Valor por hora: 25000
```

**Salida esperada**

``` text
Empleado: Juan Pérez
Horas trabajadas: 48
Valor por hora: $25000
Salario total: $1200000
```

## Ejercicio 2. Conversor de temperatura

### Enunciado

Desarrolle un programa que solicite una temperatura en grados Celsius y
la convierta a grados Fahrenheit y Kelvin.

-   Fahrenheit = (C × 9/5) + 32
-   Kelvin = C + 273.15

**Ejemplo de entrada**

``` text
Temperatura en Celsius: 30
```

**Salida esperada**

``` text
Temperatura en Celsius: 30°C
Temperatura en Fahrenheit: 86.0°F
Temperatura en Kelvin: 303.15 K
```

## Ejercicio 10. Conversión de pesos colombianos

### Enunciado

Solicite una cantidad de dinero en pesos colombianos (COP) y conviértala
a dólares estadounidenses (USD) y euros (EUR).

Tasas: - 1 USD = 4000 COP - 1 EUR = 4600 COP

**Ejemplo de entrada**

``` text
Pesos colombianos: 920000
```

**Salida esperada**

``` text
Pesos colombianos: $920000
Dólares: $230.00 USD
Euros: €200.00 EUR
```
