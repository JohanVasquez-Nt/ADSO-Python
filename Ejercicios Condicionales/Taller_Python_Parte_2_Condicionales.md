# Ejercicio 11. Número mayor entre dos valores

## Enunciado

Desarrolle un programa que solicite dos números enteros e indique cuál de ellos es el mayor. Si ambos números son iguales, el programa debe informarlo.

### Ejemplo de entrada

```text
Número 1: 45
Número 2: 18
```

### Salida esperada

```text
El número mayor es: 45
```
